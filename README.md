# ML / DL study

Study for the ML/DL lab entry exam (Oct 2026 – Jan 2027). Every algorithm is implemented from scratch first, then compared with the library version.

| Folder | Contents |
|---|---|
| `weekN/` | Weekly exercises (run `python3 <file>.py` to check them) |
| `implementations/` | From-scratch implementations: linear/logistic regression, CART, k-means, PCA, MLP, CNN, VAE, … |
| `notebooks/` | Experiments and plots |

## Setup
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```
